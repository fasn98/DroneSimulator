# Dust Storm Simulation & Advanced Telemetry Guide

## Accessing Dust Storm Simulation

### Quick Setup for Mars Dust Storm Testing:

1. **Open Web Interface**: Navigate to the running simulation at http://localhost:5000

2. **Configure Simulation**:
   - **Drone Model**: Select `acoustic_hexacopter_optimized` (optimal for extreme conditions)
   - **Environment**: Select `mars` (automatically enables dust storm effects)
   - **Mission Type**: Select `reconnaissance` (provides comprehensive telemetry)

3. **Start Simulation**: Click "Start Simulation" - dust storm effects activate immediately
